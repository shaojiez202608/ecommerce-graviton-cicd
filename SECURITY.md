# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through the hosting platform's private vulnerability reporting feature
(for example, "Report a vulnerability" under the repository's Security tab). Include:

- what is affected (file, stack, resource type),
- how to reproduce it in a sandbox account,
- the impact you expect.

You will get an acknowledgement, and fixes are coordinated before any public disclosure.

If the issue concerns an AWS service itself rather than this sample, report it to AWS via
https://aws.amazon.com/security/vulnerability-reporting/.

## Scope

This is a prototype for non-production environments. See `SECURITY-NOTES.md` for the known
risks and `docs/handover.md` for the hardening checklist before any production use.
